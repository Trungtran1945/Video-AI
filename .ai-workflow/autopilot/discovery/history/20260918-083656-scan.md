## Evidence

## Type

## Priority

## Autonomy

## Evidence

When a client passes `{ voice_provider: null }` or `{ default_style: null }` to clear or reset a preference, `String(null)` produces the literal string `"null"`, which is stored in the database and subsequently fails provider lookups.

## Affected Areas
- `backend/src/routes/v1/settings.js`

## Expected Outcome
Explicitly handle null: `out[f] = patch[f] === null ? null : String(patch[f])`, ensuring null values are preserved in database columns.

## Constraints
Preserve integer field parsing and existing validation rules for `INT_FIELDS`.
