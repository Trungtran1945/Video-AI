## 1. CRITICAL BUGS

### BUG 1 – OCR returns fake content

File:
backend/src/services/composerService.js

Current behavior:
When Vision OCR fails or returns no text, the service generates placeholder text:

`Text from ${asset.name || 'image'}`

It then saves this fake result to provider_cache and assets.

Required changes:
- Remove fake OCR fallback.
- Distinguish successful OCR, no text detected and provider failure.
- Do not cache failed OCR results.
- Do not save placeholder content.
- Return meaningful status and error information.
- Preserve legitimate OCR caching.

### BUG 2 – Translation reports success when providers fail

File:
backend/src/services/composerService.js

Current behavior:
When Translation Provider and LLM fallback both fail, the service returns the original text as translated text and caches it.

Required changes:
- Never return original text as a successful translation.
- Never cache failed translations.
- Return a clear provider failure response.
- Preserve fallback behavior when providers are available.
- Fix asset-level cache validation.

Translation cache identity must include:
- Source text hash.
- Source language.
- Target language.
- Relevant provider/configuration version.

When users edit OCR text and translate again, the service must not return an outdated translation.
